# Telegram-бот для заявок на вступление

Бот на aiogram 3 отправляет личное сообщение пользователю при новой заявке на вступление. Заявки остаются без изменений.

## Запуск

1. Задайте переменную окружения `BOT_TOKEN` на хостинге. Для локального запуска можно вместо этого создать `token.txt` рядом с `main.py` и вписать в него токен.
2. Установите зависимости: `python -m pip install -r requirements.txt`.
3. Запустите: `python main.py`.

Переменная `BOT_TOKEN` имеет приоритет над `token.txt`. Файл `token.txt` намеренно не добавляется в Git. Не публикуйте токен; если он уже раскрыт, отзовите его через @BotFather.
